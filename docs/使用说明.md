# AR 卡片礼物使用说明（MVP 占位版）

## 入口

- 网页地址（当前 GitHub Pages）：https://w-h-yuan.github.io/ar-card-gift-mvp/
- 二维码文件：部署后由 `docs/qr_ar-card-gift-mvp.png` 提供，贴在卡片背面角落即可。
- 微信扫 / 浏览器扫均指向同一 HTTPS 网页；如果微信内提示无法使用摄像头，点右上角“在浏览器打开”。

## 打开步骤

1. 扫码或用浏览器打开上面的网址。
2. 点击“打开摄像头”，允许授权。
3. 将占位门票据对准相机，等待识别；识别成功会出现「已识别卡片，AR 出现了」。
4. 页面会叠加占位门票平面、3D 旋转花朵和祝福文案；点击“播放祝福视频”可全屏播放占位视频。
5. 点击“返回”可退回开始页。

## 当前状态

- MVP 占位版：素材均为占位（`assets/ticket.png`、`assets/blessing.mp4`、`assets/copy.txt`）。
- 目标：验证扫码 -> HTTPS 网页 -> 摄像头授权 -> MindAR 目标识别 -> 3D + 视频叠加整条链路。
- 尚未完成双端真机测试，测试记录见 `docs/测试记录.md`。

## 换真实素材（不改代码）

1. 用同名字文件替换 `site/assets/` 或部署仓 `assets/` 下文件：
   - `ticket.png`：卡片设计图（建议 >1000px、清晰、对比强、避免大片纯色）
   - `blessing.mp4`：祝福视频（建议 1080p 以内、30 秒内、体积 <30MB）
   - `copy.txt`：文案（姓名 / 日期 / 祝福语）
2. 若换了 `ticket.png`，必须重新生成 MindAR 目标文件：
   - `targets.mind`。生成方法见 `docs/SOP.md` 或源工作区 `tools/compile`。
3. 在 `config.js` 修改文案与开关后重新部署。
4. 网址不变时，纸质卡片上的二维码无需重印。
